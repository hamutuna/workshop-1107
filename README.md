# のびっと

ブラウザ作業に集中しすぎて同じ姿勢が続かないように、15分ごと（または15分後に1回）、チャイム音とChromeの通知で「のびっと」ひと休みを促すChrome拡張機能です。

## 使い方

1. ツールバーの「のびっと」アイコンを押す（ショートカット：Alt+Shift+N／Macは Option+Shift+N）
2. 「鳴り方」で「繰り返し（15分ごと）」か「1回だけ（15分後）」を選ぶ
3. 「開始」を押す。その場でお試しの音と通知が出るので、届いたか確認してください。動作中はアイコンに「ON」と表示されます
4. 止めるときは、ポップアップの「停止」か、通知の「停止」ボタンを押す

「動作チェック」で、音と通知をいつでも試せます。届かない場合は、Macの「システム設定」→「通知」→「Google Chrome」と、音量・集中モードを確認してください。

## 使っている権限

| 権限 | 理由 |
| --- | --- |
| alarms | 15分のタイミングを計るため |
| storage | 鳴り方の設定を保存するため |
| notifications | Chromeの通知でお知らせするため |
| offscreen | チャイム音を鳴らすため |
