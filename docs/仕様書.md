# のびっと 仕様書（初版）

元になった構想メモ：`docs/Chrome拡張機能構想メモ`

## 目的

ブラウザでの作業に集中しすぎて同じ姿勢が続き、腰（腰椎椎間板症）が悪化するのを防ぐ。
ブラウザ上で起動・設定でき、時間になったら音と通知で知らせる。

## 名前

のびっと

## 初版でやること

| 項目 | 内容 |
| --- | --- |
| 間隔 | 15分（固定） |
| 開始・停止 | ツールバーのアイコンから開くポップアップで操作する。ほかのタブで作業中でもすぐ開ける |
| ショートカット | Alt+Shift+N（Macは Option+Shift+N）でポップアップを開く。`chrome://extensions/shortcuts` で変更可 |
| 鳴り方の設定 | 「繰り返し（15分ごと）」と「1回だけ（15分後）」を選べる。選択は保存され、次回も引き継ぐ |
| お知らせ | 時間になったら、チャイム音を鳴らし、Chromeの通知（デスクトップ通知）を出す |
| 繰り返し中の停止 | ポップアップの「停止」ボタン、または通知の「停止」ボタン |
| 動作中の表示 | 動作中はツールバーアイコンに「ON」バッジを出す。ポップアップには次のお知らせまでの残り時間を表示 |
| 開始時のお試し | 「開始」を押すと、その場で1回だけチャイム音と「開始しました」の通知を出し、「音と通知は届きましたか？」の案内（届かない場合のMacの確認先）を表示する |
| 動作チェック | ポップアップの「動作チェック」で、音と通知をいつでも試せる |
| 通知許可の自動確認 | Chrome側でこの拡張機能の通知が拒否されている場合、ポップアップに警告を表示する（`chrome.notifications.getPermissionLevel()`） |

- Macの「システム設定」の通知許可・集中モード・音量は、拡張機能からは確認できない。そのため、実際に音と通知を出して利用者に確かめてもらう方式にする。

- 動作中に鳴り方を切り替えた場合は、次のお知らせの時刻はそのままで、それ以降の動きだけが変わる。
- 「1回だけ」の場合、鳴ったら自動で停止状態に戻る。

## 今回はやらないこと

- 間隔を任意の時間に変える
- 画面の多言語化（ポップアップや通知の文言は日本語のみ）

## 技術メモ

- Manifest V3。15分の計測には `chrome.alarms` を使う（Service Worker が休止しても動く）。
- Service Worker は音を出せないため、Offscreen Document 内で Web Audio API を使いチャイム音を合成する（音声ファイル・外部リソースは使わない）。

### permissions と理由

| permission | 理由 |
| --- | --- |
| `alarms` | 15分後・15分ごとのタイミングを、ブラウザを閉じない限り確実に計るため |
| `storage` | 鳴り方の設定（繰り返し／1回だけ）と動作状態を保存するため |
| `notifications` | 時間になったことをChromeの通知で知らせるため |
| `offscreen` | Service Worker から音を鳴らすために、見えないページ（Offscreen Document）を使うため |

`host_permissions` やコンテンツスクリプトは使わない（閲覧中のページには一切触れない）。

## アクセシビリティ

- ポップアップはすべてキーボード（Tab・Space・Enter・矢印キー）で操作できる。
- 状態の変化（開始・停止）は `role="status"` で読み上げる。残り時間は毎秒は読み上げない。
- 鳴り方の選択は `fieldset` / `legend` 付きのラジオボタン。
- 文字と背景のコントラストは WCAG AA（4.5:1）以上。フォーカス枠を見やすく表示する。
- 音だけでなく通知（視覚）でも知らせる。
